# Dependencies

This page lists the main third-party components used by Luogo-FOSS and what each
one is for. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for
attribution.

- **Kotlin** — Android app language
- **Jetpack Compose** — UI
- **Room** — local database
- **AndroidX** — platform libraries
- **Kotlin backend** — self-hostable relay (see `relay/`)
